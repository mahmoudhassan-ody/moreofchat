## P1b exit criteria

Closed 2026-08-19. Each line carries its evidence.

- [x] **All 23 cases run through both stages.** 22 authored plus re-0023, added
  in this plan. None errored. Education's 17 run separately, so 40 across both
  files — asserted by id and as a floor, not as a literal total, because both
  files are append-only.
- [x] **`arithmetic_in_model_rate` measured, 0.0%, 1 observation.** Thin, and
  honestly so: exactly one case pins an `expected_computation`. The gate
  counted `check_tool_calls` as well until 2026-08-19 and read 60% over 15
  observations, 14 of them tool calls — a zero-tolerance commercial gate
  reporting slot extraction. An end-to-end test now asserts only the
  computation check contributes.
- [x] **`type_substitution_rate` measured, 0.0%, 8 observations.** It read
  11.1% until the same split: a turn presenting units with no resolved
  `property_type` was counted as a substitution, though the customer had named
  no type to substitute for. That population is now `unresolved_type_rate`.
- [x] **`invented_compound_rate` measured, 0.0%, 12 observations.** Every
  compound named in a reply came from a catalogue row.
- [x] **`sold_unit_offered_rate` measured, 0.0%, 12 observations.** No sold or
  reserved unit was offered anywhere in the suite. The snapshot holds all 305
  rows including the 15 sold and 8 reserved, which is what makes this gate
  capable of failing.
- [ ] **`asof_disclosure_rate` measured, 72.2%, 18 observations — below the
  0.98 threshold.** Diagnosed, not tuned. All 5 misses are turns the case
  expects to *answer* and which instead produced the fallback clarification,
  because the keyword extractor recognised no intent. None is a handoff or a
  refusal. The cases are not wrong to require disclosure and the replies are
  not wrong to omit it on a clarification — the turns simply never reached the
  inventory path. This closes when the extraction prompt exists; see below.
- [x] **The availability filter proven load-bearing by sabotage.** Removing the
  clause from `_where` fails 5 tests including
  `test_a_sold_unit_is_unreachable_even_by_id`. Reverted from a scratchpad
  copy; 18 pass.
- [x] **All 189 planned fixture schedules reconcile to their price exactly.**
  One parametrized test per unit, so a single disagreement names itself.
  Sabotage-proven three ways: `round()` for floor fails 62, spreading the
  remainder fails 129, computing unoffered terms fails 2.
- [x] **`re-0002` and `re-0021` produce the two distinct no-match shapes.**
  re-0002 answers naming both compounds; re-0021 hands off naming none,
  because all five villas are 23.9M+ and naming one above budget would answer
  a different question.
- [x] **`re-0022` does not offer a chalet.** The North Coast is 19 chalets and
  zero studios, so a chalet is the ranked-first answer for any naive
  retriever. The requested type is pinned into the query rather than preferred
  by a ranker, so the wrong type is never a candidate.
