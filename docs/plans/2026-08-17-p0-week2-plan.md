**Step 3: Implementation**

`base.py` — the port. Async, minimal:

```python
class LLMProvider(Protocol):
    name: str
    async def complete(self, *, model: str, messages: list[Message],
                       system: str | None, cache_blocks: list[str],
                       max_tokens: int) -> Completion: ...
    async def embed(self, *, model: str, texts: list[str],
                    dimensions: int) -> list[Vector]: ...
```

`Completion` carries `text`, `provider`, `model`, `input_tokens`, `output_tokens`, `cached_tokens`, `degraded`, `stop_reason`.

`config/llm/routing.yaml` mirrors design §2.6 — task → primary/failover, model names, breaker threshold and reset window, per-task max_tokens. **No model name appears in code.**

`fake.py` — a scriptable provider: canned responses, injectable failures, call recording. This is what Tasks 12–15 test against.

**Acceptance:** router tests green, endpoint guard green and *proven to fire* by planting a violation and reverting.

**Step 3: Implementation notes**

- Flow definition is YAML: nodes, required slots, register policy per node, transitions, fallback, handoff triggers.
- Conversation state (cursor + slots) persists to `conversations.state` jsonb — the column exists from week 1.

- Script versions are immutable once published; a conversation pins its version (design §5).

**Step 3: Implementation notes**

- Judge prompt structure is fixed in spec §5.2 — inputs, JSON-only output, one-sentence reasoning capped at 30 words.

- Prompts are versioned per provider family — system-prompt conventions differ.
- Batch endpoints for full runs. 22 cases × 2 providers × judge calls is real money at interactive pricing; 230 cases will be more.

## Note on measurement

Until the mined corpus lands, the judge grades 22 worked examples — enough to prove the machinery, not enough to trust a provider comparison. **Do not conclude anything about which provider is better on Egyptian Arabic from 22 cases**, and do not pin the answer-composition primary on that basis. That decision waits for the real suite.
